# CHNA Reference Guide

A **Community Health Needs Assessment (CHNA)** is a report that every
not-for-profit (501(c)(3)) hospital facility in the United States must conduct
**at least once every three years** and adopt an accompanying implementation
strategy, under **IRS section 501(r)(3)** (added by the Affordable Care Act,
§9007). Failure to comply can trigger a $50,000 excise tax per facility and
threaten tax-exempt status.

## IRS 501(r)(3) — required elements

A compliant CHNA must:

1. **Define the community served** by the hospital facility, and describe how
   it was determined.
2. **Assess the health needs** of that community — using data and input.
3. **Solicit and take into account input** from persons who represent the
   broad interests of the community, including those with **public health
   expertise**, and **medically underserved, low-income, and minority
   populations**.
4. **Document** the process and results in a written report adopted by an
   authorized governing body.
5. **Make the report widely available to the public** (e.g., on a website).
6. Be paired with an **implementation strategy** describing how the hospital
   will address the prioritized needs (or why it will not address some).

## Typical report anatomy

CHNAs vary by author/consultant, but most contain these sections (use them as
landmarks when extracting):

| Section | What it contains |
| --- | --- |
| Executive summary | High-level findings and prioritized needs |
| Introduction / purpose | Regulatory context, hospital background |
| Community description | Geography, service area, demographics |
| Methodology | Data sources, partners, input process |
| Secondary data | Health indicators vs. state/national benchmarks |
| Primary data | Surveys, focus groups, key-informant interviews |
| Prioritized health needs | The ranked list of significant needs |
| Resources / assets | Existing community resources to address needs |
| Implementation strategy | Goals, actions, metrics (often a separate doc) |
| Evaluation of prior CHNA | Progress on the previous cycle's plan |

## Common health indicators to look for

- **Chronic disease**: obesity, diabetes, heart disease, hypertension, cancer.
- **Behavioral health**: mental health, depression, suicide, substance use.
- **Access**: uninsured rate, primary care provider ratio, dental access.
- **Maternal & child**: prenatal care, low birth weight, infant mortality.
- **Social determinants**: poverty, food insecurity, housing, education,
  transportation.
- **Health behaviors**: smoking, physical inactivity, excessive drinking.

Indicators are most meaningful **relative to a benchmark** (county vs. state
vs. national, or current vs. prior cycle). When extracting, always keep the
comparison columns.

## Compliance checklist

When auditing a report, confirm each item is present and dated within the last
three years:

- [ ] Community served is defined, with the method used to define it.
- [ ] Significant health needs are identified and **prioritized**, with the
      prioritization criteria stated.
- [ ] Community input is described, including input from public-health experts
      and underserved/low-income/minority populations.
- [ ] Data sources are cited (secondary data + primary data collection).
- [ ] An evaluation of the impact of the **prior** CHNA's actions is included.
- [ ] The report was adopted by an authorized governing body (with date).
- [ ] An implementation strategy exists and maps actions to prioritized needs.
- [ ] The report is made widely available to the public.
